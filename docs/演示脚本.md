# 演示脚本 —— Virtual Being（AI 虚拟人物，M6 打磨展示）

> 目的：让任何人都能照做一遍，把 M1-M5 的能力完整演示出来（文本对话 → 语音对话 → 形象表情 → 知识/计算能力 → 记忆）。
> 每步都给出**操作**、**预期效果**与**截图指引**；演示失败时先看文末「常见问题排查」。

## 0. 前置准备（约 5 分钟）

| 项目 | 要求 | 检查命令 / 说明 |
| --- | --- | --- |
| Python | 3.9+，虚拟环境已建 | `python --version` |
| 依赖 | 已安装 | `.venv\Scripts\python.exe -m pip install -r requirements.txt` |
| Ollama | 已启动且已拉取模型 | `ollama list` 应含 `qwen2.5:7b`；未拉取执行 `ollama pull qwen2.5:7b`（约 5GB） |
| ASR 模型 | 首次使用需本地下载 | 默认 `data/models`（`ASR_MODEL_DIR`）；无本地模型时首次启动联网下载，直连不稳设 `HF_ENDPOINT=https://hf-mirror.com` |
| TTS 联网 | edge-tts 需访问微软在线服务 | 无网时语音合成会如实报错，可跳过「步骤 3」 |

> 隐私提示：用户语音原始数据不落库（API 处理完即删）；全程使用本地 Ollama，无需云端 API key。

## 1. 启动服务

**操作**：

```powershell
cd E:\work\virtual-being
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**预期效果**：

- 启动日志出现 `[startup] ASR 模型预加载完成`（M4.2 启动预加载，约 1s 内完成，无需等待模型下载）
- 浏览器打开 http://127.0.0.1:8000/health 显示 `{"status":"ok"}`

**截图指引**：截取终端启动日志（含 ASR 预加载完成行）+ 浏览器 health 页面，命名 `01_start.png`。

## 2. 文字对话（人设 + 人格）

**操作**：浏览器打开 http://127.0.0.1:8000/ ，在输入框输入「你好呀，介绍一下你自己吧」并回车。

**预期效果**：

- 消息发送后立绘切换为**思考**表情（徽标显示"思考中"）
- 收到温柔治愈风格回复（如"嗯嗯，你好呀！我是小暖……"），回复逐字出现时立绘为**说话**表情，说完短暂**开心**后回到默认
- 会话延续：继续问「那你能帮我做点什么呀？」能结合上下文回答

**截图指引**：截取完整聊天窗口（含立绘表情 + 对话气泡），命名 `02_text_chat.png`。

## 3. 语音对话（说→听→回→播）

**操作**：点击输入框右侧 🎙 按钮并**按住**，说一句中文（如"我最近有点累，陪我聊聊天好吗"），松开发送。

**预期效果**：

- 按住时按钮变红脉动、提示"正在聆听…"，松开后短暂"思考中"
- 你的语音被识别为文本显示在对话窗（🎤 前缀）
- TA 的回复文字逐字出现，随后**自动播放**回复音频（可从界面确认在播放）
- 立绘表情随"思考 → 说话 → 开心"切换

**截图指引**：截取语音回复完整消息（含 🎤 识别文本 + 回复 + 立绘），命名 `03_voice_chat.png`。
若想快速复现：也可用 CLI 全链路自检 `python -m scripts.run_voice_demo --self-test`（自动生成中文输入）。

## 4. 表情状态展示

**操作**：连续发送 2-3 条消息（如"今天天气不错呢""你最喜欢什么颜色"），观察立绘表情变化；再说一句开心话题（如"我中奖啦！"）观察**开心**表情。

**预期效果**：默认 / 思考 / 说话 / 开心 四种表情均可观察到，切换平滑无卡顿；风格温柔治愈不违和（眯眼笑 + 腮红 + 大笑容）。

**截图指引**：分别截取四种表情的立绘特写，拼图命名 `04_expressions.png`（若来不及截取，可说明录制短视频代替）。

## 5. 知识查询 + 计算能力（M2 能力 Agent）

**操作**（任选 2 条输入）：

- 「Ollama 是什么？」→ 预期：命中内置知识库，给出本地大模型工具的介绍
- 「RAG 是什么？」→ 预期：检索增强生成原理介绍
- 「我们这个项目是做什么的？」→ 预期：结合知识库与记忆介绍虚拟人物项目
- 「23 * 17 等于多少？」→ 预期：**准确计算**出 391（走计算能力 Agent，不靠 LLM 心算）
- 「300 的 15% 是多少？」→ 预期：45（支持中文运算符）

**预期效果**：意图自动路由（闲聊 vs 工具调用），计算类回答准确、无幻觉。

**截图指引**：截取知识问答 + 计算问答各一条，命名 `05_capabilities.png`。

## 6. 长期记忆效果（M3）

**操作**：

1. 输入「记住啦，我叫小明，我喜欢听周杰伦」；
2. **停止服务**（Ctrl+C），重新执行「步骤 1」启动服务；
3. 新会话输入「我叫什么名字呀？」或「我喜欢听谁的歌？」

**预期效果**：重启后仍能答出"小明 / 周杰伦"——跨会话长期记忆（SQLite 持久化，fact 抽取）生效；若 TA 答错或含糊，可用「我是小明呀」纠正（记忆有纠偏机制）。

**截图指引**：截取"记住"消息 + 重启后的"还记得我吗"问答，命名 `06_memory.png`。

- 关停服务：终端 Ctrl+C；如占用端口：`Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess | Stop-Process`
- 可选：跑一遍离线测试自证 `python -m pytest -q`（预期 90 passed）

## 常见问题排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面打不开 / 连接拒绝 | 服务未启动或端口被占；确认启动日志无报错 |
| 发送后一直"思考中" | Ollama 未启动或模型未拉取：`ollama list`；首次调用冷启动较慢属正常 |
| 语音按钮灰色不可用 | 浏览器不支持 MediaRecorder（建议 Chrome/Edge）或未授权麦克风 |
| 语音"没听清" | 环境嘈杂 / 语速快；ASR 为本地 base 模型，识别质量有限，可换 `ASR_MODEL_SIZE=small` |
| 语音回复音频不自动播放 | 浏览器自动播放策略；点击页面任意位置后再试一次 |
| TTS 报"需联网" | edge-tts 在线服务不可达；文字对话不受影响 |
| 第一次启动 ASR 卡住 | 首次需下载 ASR 模型：设 `HF_ENDPOINT=https://hf-mirror.com` 走国内镜像，或预置 `data/models` |
